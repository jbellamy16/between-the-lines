## Factual blocker fixed

Two previous shots and six current shots, each rated 0.1 xG, produced slightly different binary floating-point means. The old strict comparison published “lower.” A regression test failed on that exact case before the fix.

`questions.ts` now treats differences within `1e-12` on bounded [0,1] ratings as equal, preserving raw evidence values and genuine increases/decreases. Guided workflow version increments to `guided-1.1.1`, invalidating stale server/browser question caches. Regression cases cover equal ratings, zero, one, and changes of ±0.000001. The evaluation now requires correct verdicts in every arm; its scorer test deliberately injects the old error to retain error-detection coverage.

The same frozen 14-state corpus passes its conclusion-safety gate: A scores **216/216**, B/C/D each **360/360**, with zero unsupported conclusions, incorrect references, citation errors or missing caveats. All **40/40** invalid injected plans are rejected with fallback evidence preserved. [New result snapshot](offline-regression.json). Historical results/receipts are unchanged. These are diagnostic results, not general reliability or model-value claims; all extra facts still come from deterministic code.
